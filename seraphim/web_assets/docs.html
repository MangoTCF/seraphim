Seraphim documentation

Seraphim renders scores with seven voices. Four mouths speak at the same time, and three prayer voices sing the tense.

Compose · Dictionary · Score notation · Characters · Render and export · Local setup

Write a score in English

  1. Choose English, enter a sentence, and pick a speaker character. Each character uses a different dialect and synthesis defaults.
  2. Click Prepare score. For unfamiliar glosses, Seraphim suggests pronunciations. Review those suggestions and save any changes to an entry, then build the score.
  3. Choose a word in the score editor to change its tense, tone, stammer, or four mouth lines. Apply your edits, then insert, reorder, or delete words as needed. Undo reverses your last change in the editor.
  4. Render from the score editor, or download the .sera file and render later.

English translation is rule-based and approximate. Use Gloss for more explicit grammatical input, or open a .sera file to work from an existing score. To edit title, metadata, or sentence breaks, open Score source and metadata in the score editor and apply the changed source.

Dictionary and saved drafts

Search by gloss, part of speech, or pronunciation. Save an override for an installed entry or create a new gloss. Removing an override restores the installed entry if one exists. The editor checks token syntax and rejects pronunciations that collide with another gloss.

The workbench uses your overrides and accepted pronunciations when it builds a score from English or gloss input. Generated scores embed the vocabulary they use. Rebuild a composition from its English or gloss draft to pick up dictionary changes.

Your browser saves drafts, settings, and dictionary overrides for each server address. Clearing site data deletes those drafts. If you change ports, open the original address to find them. Download a score to keep a portable copy.

Score notation

@title: Example
@dialect: seraphic

word farpast+nonpast tone=fear:0.3
  top: /26/☀
  1: ~ /15/🔆
  2: Ø
  end: Ø
---
word gnomic stammer
  top: /45/☢
  • top, 1, 2, and end are the four speech mouths. Use Ø for silence and ~ before moved speech.
  • Tokens are whitespace-separated Hebrew spellings or numeric phonemes such as /26/. Use the phoneme picker to insert numeric tokens. - marks a morpheme break.
  • ☀, 🔆, and ☢ set vowel brightness. --- starts a new sentence and # starts a comment.
  • Use farpast, nearpast, nonpast, or gnomic for tense. Join tenses with + to stack them. A bare word inherits tense.

Speaker characters

  • Seraphic is the default, with clean voices and forward Dorian prayer.
  • Cupid has a teasing lilt, swelling vowels, and a close whisper.
  • Succubus has breathy, intimate voices and reversed Phrygian prayer.
  • Nephilim combines two seraphic and two fallen speech mouths, which can trade sides.
  • Demonic has differently damaged speech mouths and low, reversed Locrian prayer.

The far past and gnomic tenses use Aramaic, the near past uses Greek, and the non-past uses Latin. Stacked tenses distribute across the prayer voices.

Render and export

Rendering uses the current score and your sound settings. Pick a character to see its illustration and use its dialect on the next render. To record a character choice in the source of an existing score, edit @dialect.

After rendering, play the full ensemble, solo a mouth, or select a word to inspect its parts and seek to it. The workbench can export WAV audio, a timing plan, and a bundle with stems, score, and render settings.

seraphim check score.sera
seraphim synth score.sera -o out/score.wav

Local setup

From the project checkout, install the English extra and language model, then launch the workbench.

python -m venv .venv
.venv/bin/python -m pip install -e '.[english]'
.venv/bin/python -m spacy download en_core_web_sm
.venv/bin/seraphim-web

Open the localhost address printed by the server. The workbench uses the spaCy model to parse English. Gloss and score input can run with the base package.
